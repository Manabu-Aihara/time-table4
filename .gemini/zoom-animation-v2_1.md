# タイムラインのズームアニメーション機能（25/09/30改訂版）

## 1. 要件定義

### 1.1. 背景・目的

現行のズーム機能は、タイムライン全体でドラッグイベントを検知するため、本来のドラッグによるスクロール機能と競合しています。
この問題を解決し、**ドラッグによる「ズーム機能」と「スクロール機能」を両立させる**ため、ズームが機能する範囲をタイムライン上のイベントアイテムに限定します。

### 1.2 機能概要

- タイムラインの**イベントアイテム上**でドラッグ操作を行った場合にのみ、ズーム機能を有効にします。
- タイムラインの背景など、アイテム以外の部分をドラッグした場合は、タイムラインのスクロール機能が動作するようにします。

### 1.3 機能要件

- ズームのトリガー条件を「タイムライン全体のドラッグ」から「イベントアイテム上のドラッグ」に変更します。
- ズームアニメーションのロジックや視覚表現については、`zoom-animation-v2.md`で定義された内容を引き継ぎます。

### 1.4 非機能要件

- `zoom-animation-v2.md`の非機能要件を引き継ぎます。

## 2. 機能設計

### 2.1. アーキテクチャ

**ドラッグ開始位置の判定による機能切り替え:**

- `TimelineComponent.tsx`に`onMouseDown`イベントリスナーを設定します。
- イベント発生時、`event.target`（クリックされたDOM要素）を解析します。
- `event.target.closest('.rct-item')`のようにDOMを探索し、ドラッグがイベントアイテム（`react-calendar-timeline`が生成するアイテム）上で開始されたかを判定します。
- 判定結果に応じて、以下の処理を振り分けます。
    - **アイテム上の場合:** ズーム処理を開始します。既存の`useTimelineDragZoom`フックのロジックを呼び出します。
    - **アイテム外の場合:** 何もせず、`react-calendar-timeline`のデフォルトのスクロール挙動に委ねます。

### 2.2. 実装詳細

- **対象コンポーネント:** `/home/nabu_dvl/workspace/time-table4/src/components/pages/TimelineComponent.tsx`
- **カスタムフックの改修:** `src/hooks/useTimelineDragZoom.ts`
    - `onMouseDown`ハンドラ内で、ドラッグ開始位置がアイテム上かどうかを判定するロジックを追加します。
    - アイテム上でない場合は、ズーム関連の状態（`isDragging`など）を更新しないように変更します。
- これにより、`onItemDrag`プロパティを使用することなく、目的の挙動を実現します。
- 既存の`onTimeChange`プロパティは、タイムラインのスクロールをハンドルするために引き続き利用します。

- **ファイル構成案:**
    - `src/hooks/useTimelineDragZoom.ts` (改修)
    - `src/components/pages/TimelineComponent.tsx` (改修)
    - `src/lib/TimelineType.ts` (必要に応じて型定義を追記)
